# ORBITAL GUARD

Прототип мониторинга околоземных объектов для NASA Space Apps Challenge. Интерфейс показывает реальные элементы орбит CelesTrak и положения, распространённые на текущее время библиотекой Skyfield (модель SGP4).

## Запуск локально

Требуются Node.js 20.19+ и Python 3.10+.

1. Установите frontend-зависимости:

   ```powershell
   npm install
   ```

2. Установите backend-зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r backend\requirements.txt
   ```

3. В первом терминале запустите API:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   uvicorn backend.main:app --reload
   ```

4. Во втором терминале запустите интерфейс:

   ```powershell
   npm run dev
   ```

   Откройте адрес Vite, обычно `http://localhost:5173`.

API-документация доступна по адресу `http://127.0.0.1:8000/docs`. Проверка готовности: `http://127.0.0.1:8000/api/health`.

## Данные и ограничения

- Источник орбитальных элементов: [CelesTrak GP data](https://celestrak.org/NORAD/elements/gp.php), группы `active`, `debris`, `rocket-body` и `stations`, формат OMM JSON.
- Каталог кэшируется backend в памяти на 15 минут и сохраняется в `backend/.cache/` для повторного запуска. Если upstream временно недоступен, интерфейс явно показывает использование кэша и время его загрузки; при отсутствии кэша возвращается ошибка, демонстрационные объекты не подставляются.
- Положение и траектория рассчитываются Skyfield/SGP4 по доступным элементам на время запроса. Возраст элемента отображается отдельно.
- CelesTrak GP не предоставляет в этом интерфейсе подтверждённые сведения о владельце. Такие сведения не выдумываются.
- «Близкие объекты» — только мгновенные расстояния между распространёнными положениями объектов в загруженной выборке. Это не прогноз сближения или столкновения: ковариации, неопределённость и вероятность столкновения не рассчитываются. Результат не следует использовать для операционных решений.
- 3D-глобус использует картографические тайлы OpenStreetMap; для их загрузки требуется интернет.
- MVP показывает до 2 000 объектов выбранной группы на карте. Общий размер доступного каталога указывается отдельно; поиск выполняется по полной группе источника перед применением лимита.

## Структура

- `src/` — React/TypeScript dashboard и CesiumJS-глобус.
- `backend/main.py` — FastAPI, получение/кэширование данных CelesTrak, распространение орбит, оценка свежести и описательный анализ близости.
